Section 01

System Overview & Design Philosophy

LayoutForge is an AI-augmented visual layout builder, canvas editor, and code generation engine built for modern web applications. It bridges the gap between Figma-style freeform visual manipulation and production-grade software engineering, enabling users to assemble pages visually, explore curated design vibes inspired by Google Stitch, and export 100% clean, semantic code.

Core Architecture Paradigm: Dual Coordinate & Dual Layout Engine

Unlike simple block builders that restrict components to rigid 1D vertical stacks, LayoutForge runs an interactive 2D spatial canvas with sub-pixel absolute coordinate placement (1440px desktop reference), coupled with a sophisticated Semantic Flow Compiler (`src/engine/responsive.js`) that compiles absolute geometric placements into clean, responsive CSS Flexbox/Grid structures with clamp() fluid typography and dynamic viewport adaptation.

🎯
Freeform Visual Studio
Sub-pixel drag-and-drop, 8-handle box resizing, magnetic snap guides, multi-selection, and group translation.
🧠
Offline Heuristic AI
Zero external API dependencies or latency. Deterministic natural language synthesis and HTML5 Canvas pixel sampling for image-to-design mockups.
📦
Multi-Stack Code Export
One-click downloads of zero-dependency HTML5/CSS single files, or full React 18 + TypeScript + Material UI (MUI v5) zip bundles.

Application Coding Flow & Execution Lifecycle

The following flow diagram illustrates how data, user events, and state mutations move through LayoutForge from bootstrap to canvas rendering and export:

1
App Initialization (main.tsx & App.tsx)
main.tsx wraps the application in Material UI's ThemeProvider with light studio theme tokens and mounts App.tsx. App.tsx establishes the global DndContext with pointer sensors, initializes modal states, and registers global keyboard shortcuts (e.g. Ctrl+K for AI Modal).

3
3-Column Studio Layout Assembly
The workspace renders into three primary columns:
  • LeftSidebar: Renders Element Palette (19+ drag items), Layers Tree, and Stitch Blocks.
  • Center Canvas: Renders Artboard, grid overlay, magnetic snap guides, elements, and the floating Stitch Command Bar.
  • RightSidebar: Contextual Properties Inspector. Displays element-specific controls (Geometry, Typography, Content, Colors, Borders, Animations) if an item is selected, or Page Settings if canvas background is clicked.
4
User Interaction & Reactive Store Updates
When a user drags, resizes, types content, or changes colors, actions call store mutations (e.g., updateElement, setElementGeometry). The store pushes snapshots into the 40-step history array for undo/redo and automatically writes updates to localStorage.
5
Responsive Compilation & Export
When previewing or exporting, responsive.js groups absolute 2D elements into semantic horizontal rows, computes fluid clamp() typography, and passes structured AST to htmlGenerator.js or reactMuiGenerator.ts.
Section 06

How Drag and Drop Component Logic Works

LayoutForge implements a sophisticated Two-Stage Drag and Drop Architecture designed to deliver smooth 60fps performance and sub-pixel accuracy:

Stage 1: Palette-to-Canvas Drop (@dnd-kit)

When dragging a new element from the left component catalog into the artboard:

Drag-and-Drop Coordinate Normalization Math in App.tsx 
// 1. PointerSensor activation constraint (requires 4px movement before drag initiates)
const sensors = useSensors(
  useSensor(PointerSensor, { activationConstraint: { distance: 4 } })
);

// 2. Drop Coordinate Translation inside handleDragEnd
const handleDragEnd = (event: DragEndEvent) => {
  const { active, over, delta, activatorEvent } = event;
  if (!over || over.id !== 'canvas-artboard') return;

  const currentData = active.data?.current;
  if (currentData?.isPaletteItem && currentData.type) {
    const artboardEl = document.querySelector('[data-canvas="artboard"]');
    const mouseEv = activatorEvent as MouseEvent;
    const rect = artboardEl.getBoundingClientRect();

    // Map screen mouse coordinates + drag delta relative to artboard and zoom factor
    const dropClientX = mouseEv.clientX + delta.x;
    const dropClientY = mouseEv.clientY + delta.y;

    let rawX = (dropClientX - rect.left) / zoom;
    let rawY = (dropClientY - rect.top) / zoom;

    // Apply magnetic grid snapping if enabled (e.g. 10px / 20px grid)
    if (snapToGrid) {
      rawX = Math.round(rawX / gridSize) * gridSize;
      rawY = Math.round(rawY / gridSize) * gridSize;
    }

    // Clamp coordinates to stay cleanly inside the artboard boundaries
    const dropX = Math.max(20, Math.round(rawX));
    const dropY = Math.max(20, Math.round(rawY));

    addElement(currentData.type, dropX, dropY);
  }
};

Stage 2: On-Canvas Transform & Resizing (react-rnd)

Once on the canvas, each element is wrapped by a <Rnd> container from react-rnd:

  • Positioning: Driven by position={{ x: element.x, y: element.y }} and size={{ width: element.width, height: element.height }}.
  • 8-Point Resize Handles: Handles on top, bottom, left, right, and all four corners with visual hover pills.
  • Minimum Dimensions: Bound by minWidth={30} and minHeight={20} to prevent accidental collapse.
  • Locked Elements: When element.locked === true, disableDragging={true} and resize handles are disabled.

Stage 3: Multi-Element & Hierarchical Group Movement

Moving multiple elements simultaneously is a notoriously difficult performance challenge. LayoutForge solves this with Direct DOM Matrix Translation:

A
Group Identification (groupingUtils.ts)
On onDragStart, getRelatedGroupIds() checks if the user has multi-selected elements via Shift + Click, marquee box selection, or if the dragged element is a container holding children.
B
60fps DOM Bypassing during Drag
Instead of triggering React re-renders on every mouse move, LayoutForge directly updates the CSS transforms of sibling elements: node.style.transform = `translate3d(${dx}px, ${dy}px, 0)`. This ensures zero jank and fluid 60fps animations.
C
Batch State Commit on Drop
When the user releases the mouse (onDragStop), the DOM transforms are reset and moveElementsGroup(primaryId, relatedIds, dx, dy) commits the new final X/Y coordinates to Zustand and the undo/redo history in a single atomic batch.
Section 07

How AI Features Logically Work

A key engineering achievement of LayoutForge is its 100% Offline, Privacy-First, Zero-Latency AI Architecture. There are no expensive API keys, no external network calls, no rate limits, and complete data privacy.

1. Natural Language Prompt-to-Layout Engine (`aiLayoutEngine.js`)

Translates freeform English prompts (e.g. "Modern architectural design studio portfolio") into pixel-perfect pages:

  • Semantic Archetype Classification: Regular expression keyword scanning maps prompts into domain archetypes: architecture, saas, ai, agency, pricing, contact, ecommerce, mobile.
  • Domain Knowledge Bases: Each archetype contains realistic copywriting, industry badges, feature cards, checklists, stats, and authentic imagery.
  • Spatial Layout Computation: Calculates vertical offsets (y coordinate pacing), 3-column card grids, responsive navbar positions, and button margins deterministically.
  • Harmonic Palette Synthesis: Automatically assigns matched primary, accent, card surface, and font pairings (e.g. Playfair Display for Architecture, Space Grotesk for AI).
2. AI Vision Image-to-Design Engine (`imageLayoutEngine.js`)

Converts uploaded screenshots or wireframes into editable canvas elements:

  • HTML5 Canvas Pixel Sampling: Renders uploaded images onto an offscreen canvas and samples raw RGBA pixel arrays via ctx.getImageData().
  • Perceived Luminance Calculation: Calculates ITU-R BT.709 relative luminance Y = 0.2126*R + 0.7152*G + 0.0722*B to detect light vs dark mode.
  • Color Quantization: Samples top/center/bottom regions to extract dominant background colors, primary brand accents, and card surface tones.
  • Structural Layout Synthesis: Uses aspect ratio and visual heuristics to generate matching navigation bars, hero titles, card columns, and call-to-actions.

3. AI Design Critique & Auto-Polish Engine (`StitchCritiqueModal.tsx`)

Acts as an automated in-studio design lead, auditing canvas elements for accessibility and visual hygiene:

Audit Check Logic & Formula Auto-Polish Fix Action
WCAG 2.1 Color Contrast Calculates relative luminance ratio: (L1 + 0.05) / (L2 + 0.05) between text and element background. Flags if < 4.5:1. Automatically updates font color to high-contrast dark (#1A1A18) or white (#FFFFFF).
Touch Target Sizing Checks if buttons or clickable links have height < 44px or width < 44px (Apple/Google accessibility standard). Adjusts button height to 44px and expands horizontal padding.
Typography Readability Flags body text with font sizes below 12px or headings with improper line heights. Scales body text to 14.4px / 16px and normalizes line height to 1.5.
Border Radius Harmony Detects clashing border radii across adjacent cards and containers. Harmonizes border radius across all cards to the active design token standard.

Section 09

Intelligent Responsiveness & Export Engine

How Responsive Compilation Works (`src/engine/responsive.js`)

When switching between Desktop (1440px), Tablet (768px), and Mobile (375px), or exporting code, the layout engine executes three transformation stages:

1
Vertical Overlap Row Grouping
Elements are sorted by vertical position. The engine calculates whether sibling bounding boxes overlap vertically using hasVerticalOverlap(y1, h1, y2, h2, threshold = 0.3). Overlapping elements are clustered into horizontal semantic rows.
2
Automatic Card Grid Stacking
  • Desktop: Retains multi-column horizontal alignment with relative column widths (--col-width: 33.3%).
  • Tablet (768px): 3-column rows automatically re-organize into 2-column balanced grids.
  • Mobile (375px): Horizontal card rows stack vertically with full width (100%), margin adjustments, and expanded artboard height.
3
Fluid Typography Clamp Scaling
Computes mathematical CSS clamp functions for all font sizes:
calculateFluidTypography(fontSizePx) → clamp(1.2rem, 2.8vw + 0.5rem, 3.5rem)
This guarantees headlines scale fluidly between mobile and 4K displays without breaking layouts.

Code Generation Engines

Pure Semantic HTML5 + Vanilla CSS (`htmlGenerator.js`)
Generates a self-contained single-file HTML document with zero external framework dependencies, embedded CSS variables, responsive media queries, and keyframe animations. Ready to open in any browser or deploy to Netlify/Vercel.
Production React 18 + TypeScript + MUI v5 (`reactMuiGenerator.ts`)
Synthesizes a complete TypeScript codebase: App.tsx (MUI components), theme.ts (Material Design tokens), package.json, vite.config.ts, and tsconfig.json. Downloadable as a ready-to-run ZIP.
